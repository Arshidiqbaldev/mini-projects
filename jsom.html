📱 Mobile Optimized

On mobile devices (screen width < 768px), the blur is automatically reduced from 10px to 8px for better performance while maintaining the glass effect.

The GPU acceleration forces the browser to use hardware rendering instead of software rendering.

🎯 Why This Works

will-change: transform - Tells the browser to expect transform changes, creating a separate compositor layer.

translateZ(0) - Forces GPU acceleration by promoting the element to its own layer.

backface-visibility: hidden - Prevents flickering during animations and scrolling.
